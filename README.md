# Demand Forecasting for Fabric and Sewing Supplies Retail

Bachelor's thesis at Ukrainian Catholic University (2026)

## Methods

- ABC-XYZ classification (quantile-based thresholds)
- Forecasting models: SMA, SES, ARIMA(1,1,1), Prophet

## Data

The dataset is confidential and not included. Expected file names (original from the retailer):

- продажі 2021-2025 гудзики.csv
- продажі 2021-2025 тканини.csv

Original columns: Документ №, Дата, Товар, Кількість, Од. вим., Ціна продажу, В т.ч. ПДВ продажу, Вар-сть продажу, В т.ч. вар-сть ПДВ продажу.
